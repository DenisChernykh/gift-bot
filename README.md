# Gift Bot — управление розыгрышами в Telegram

Бот проводит организатора через весь процесс: подготовку розыгрыша, публикацию, регистрацию участников, завершение и получение результатов. Управление розыгрышем и взаимодействие с участниками происходят в Telegram.

## Возможности

- Пошаговый мастер подготовки и публикация поста в канале.
- Проверка прав в канале и правил участия.
- Регистрация участников, автоматическое завершение и выбор победителей.
- Перевыбор конкретного призового места и отмена розыгрыша.
- Синхронизация постов, уведомления и восстановление операций по сохранённому состоянию.

## Что показывает проект

Автоматизацию процесса, в котором база данных и внешние действия Telegram должны оставаться согласованными. Прикладные сервисы отвечают за публикацию, регистрацию, розыгрыш и восстановление; доменные правила отделены от grammY-адаптера и SQLite-хранилища. Такой подход применим к ботам, уведомлениям, обработке заявок и другим бизнес-процессам с несколькими этапами.

## Разработка

Node.js 24.18.1, pnpm@11.15.1. Переменные окружения перечислены в [.env.example](.env.example).

```sh
pnpm install
pnpm db:migrate
pnpm dev
```

```sh
pnpm check
```

Проверка объединяет lint, тесты Vitest и TypeScript-сборку.
