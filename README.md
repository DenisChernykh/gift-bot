# Gift Bot — управление розыгрышами

Telegram-бот для создания, публикации и проведения розыгрышей с управлением участниками и результатами.

## Возможности

- Мастер подготовки розыгрыша, публикация и регистрация участников.
- Автоматическое завершение, выбор победителей и перевыбор места.
- Хранение состояния, уведомления и восстановление операций.

## Инженерные акценты

- Автоматизация полного жизненного цикла бизнес-процесса.
- Согласованность состояния и внешних действий Telegram.
- Разделение прикладной логики, хранилища и Telegram-адаптера.

## Стек

TypeScript, Drizzle, grammY, Vitest.

## Навигация по коду

- [src/](src/) — исходный код.
- [tests/](tests/) — автоматизированные проверки.
- [docs/](docs/) — архитектура и документация.

## Разработка

Инструменты: Node.js 24.18.1, pnpm@11.15.1.

```sh
pnpm install
pnpm dev
pnpm check
pnpm test
pnpm build
pnpm lint
```

Параметры окружения перечислены в [.env.example](.env.example). Локальные значения задаются вне Git.
